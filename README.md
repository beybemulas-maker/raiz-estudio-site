# Raiz Estúdio

Site oficial do Raiz Estúdio — gravação, mistura e masterização em Luanda.

## Funcionalidades

- Layout responsivo e mobile-first
- Player de áudio com três faixas de demonstração
- Formulário de contacto que abre uma mensagem pronta no WhatsApp
- Botão flutuante do WhatsApp
- Links para Instagram e navegação por secções
- Menu mobile acessível

## Executar localmente

Não há dependências. Abra `index.html` no navegador ou sirva a pasta com qualquer servidor estático:

```bash
npx serve .
```

## Personalização

Substitua os URLs das faixas no `index.html` por ficheiros de áudio do estúdio e atualize textos, preços e imagens quando estiverem disponíveis.
